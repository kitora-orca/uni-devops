# 6. Перенос backup базы данных

Backup:

```text
beetles_db_full.backup
```

Передать с Windows:

```powershell
scp "C:\Users\Admin\Desktop\uni-devops\commit no oficial\full lr1\beetles_db_full.backup" admin@192.168.213.130:/home/admin/
```

На `psql`:

```bash
sudo cp /home/admin/beetles_db_full.backup /tmp/beetles_db_full.backup
sudo chown postgres:postgres /tmp/beetles_db_full.backup
sudo chmod 600 /tmp/beetles_db_full.backup
```

Создать пользователя БД:

```bash
sudo -u postgres psql
```

```sql
CREATE ROLE beetles_app LOGIN;
\password beetles_app
```

Создать базу:

```sql
CREATE DATABASE beetles_db OWNER postgres;
\q
```

Восстановить backup:

```bash
sudo -u postgres pg_restore \
  --no-owner \
  --no-privileges \
  -d beetles_db \
  /tmp/beetles_db_full.backup
```

Проверить таблицы:

```bash
sudo -u postgres psql -d beetles_db
```

```sql
\dt
\q
```

# 13. systemd-служба FastAPI

Создать:

```bash
sudo nano /etc/systemd/system/beetles.service
```

Содержимое:

```ini
[Unit]
Description=Beetles FastAPI Application
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=app
Group=app
WorkingDirectory=/opt/myapp
EnvironmentFile=/etc/beetles/beetles.env

ExecStart=/opt/myapp/venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000

Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Применить:

```bash
sudo systemctl daemon-reload
sudo systemctl enable beetles.service
sudo systemctl start beetles.service
```

Проверить:

```bash
sudo systemctl status beetles.service --no-pager
```

```bash
systemctl is-enabled beetles.service
```

```bash
sudo ss -lntp | grep 8000
```

Процесс:

```bash
ps aux | grep '[u]vicorn'
```

Он должен работать от пользователя:

```text
app
```

# 15. Nginx

Установить:

```bash
sudo apt update
sudo apt install -y nginx
```

Удалить стандартный сайт:

```bash
sudo rm -f /etc/nginx/sites-enabled/default
```

Создать:

```bash
sudo nano /etc/nginx/sites-available/beetles
```

Содержимое:

```nginx
server {
    listen 80;
    server_name 192.168.213.129;

    location / {
        proxy_pass http://127.0.0.1:8000;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

Включить:

```bash
sudo ln -sfn /etc/nginx/sites-available/beetles /etc/nginx/sites-enabled/beetles
```

Проверить:

```bash
sudo nginx -t
```

Применить:

```bash
sudo systemctl enable --now nginx
sudo systemctl reload nginx
```

# 27. Проверка секретов в Git

Файл `.env` не должен находиться в репозитории.

Проверить:

```powershell
git ls-files .env
```

Команда не должна ничего вернуть.

В `.gitignore` должна быть строка:

```text
.env
```

Вместо настоящего `.env` в репозитории можно хранить:

```text
.env.example
```

Например:

```text
DB_HOST=192.168.213.130
DB_PORT=5432
DB_NAME=beetles_db
DB_USER=beetles_app
DB_PASSWORD=change_me
SESSION_SECRET=change_me
```

# 30. Результат

После выполнения всех шагов:

```text
Клиент
   |
   | HTTP :80
   v
Nginx 192.168.213.129
   |
   | 127.0.0.1:8000
   v
FastAPI
   |
   | 192.168.213.130:5432
   v

   |

```

Приложение запускается через `systemd`, работает от отдельного пользователя `app`, автоматически запускается после перезагрузки и автоматически перезапускается после аварийного завершения.

PostgreSQL доступен по сети только серверу приложения.

Секреты находятся отдельно от исходного кода и не хранятся в репозитории.
