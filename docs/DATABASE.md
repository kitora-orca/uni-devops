\# Database



\## PostgreSQL



Проект использует PostgreSQL 17.



Название базы данных:



`beetles\_db`



\## Назначение



База данных используется приложением для хранения данных проекта.



\## Схема



Структура базы данных хранится в файле:



`docs/schema.sql`



Файл содержит структуру таблиц и других объектов базы данных без реальных данных пользователей.
